Build from this directory with:

```bash
pdflatex finite_window_gap_identifiability.tex
pdflatex finite_window_gap_identifiability.tex
```

The exact certificates, ANNNI experiments, Colab notebook, tracked results,
and figure generator live in
[`../../verification/finite_window_gap_certificates/`](../../verification/finite_window_gap_certificates/).

Claim boundary: the paper proves an information-theoretic hidden-atom no-go,
an exact flat-termination theorem, and a visibility-conditioned Chebyshev
localizer bound.  It provides finite-size evidence in an interacting spin
chain.  It does not claim a thermodynamic or Yang--Mills mass gap.
